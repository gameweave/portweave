# Reference snapshot

This directory contains **read-only** copies of selected files from the boardflip (Gameweave) codebase that originated Portweave's design. They're here so this repo is self-contained — no need to look back at boardflip during development.

## Rules

- **Do not modify these files.** They are a frozen snapshot.
- **Do not import from them at runtime.** They are documentation, not source.
- If you need updated reference, re-capture from a newer boardflip commit and update `MANIFEST.md`.

See [MANIFEST.md](./MANIFEST.md) for the source commit and per-file description.
