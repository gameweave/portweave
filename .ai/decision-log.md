| 31  | Library runtime upward-walk config discovery rule                                                             | The runtime library walks from `opts.cwd` (or `process.cwd()`) upward toward the filesystem root to find `portweave.config.json`, stopping at the first hit. This is a runtime-layer addition — the CLI's `loadConfig` reads from a single explicit directory. The walk uses `fs.access` to probe each level; non-ENOENT errors (e.g. EACCES) are rethrown.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Established 2026-05-26 by [.ai/specs/library-runtime/library-runtime.md](./specs/library-runtime/library-runtime.md).
